# AI for Software Engineering — Week 4 Assignment

This repository contains all deliverables for the AI for Software Engineering (Week 4) assignment.
It showcases multiple applications of Artificial Intelligence in software development, including:

🧩 AI-assisted code generation and comparison (GitHub Copilot vs manual implementation)

⚙️ Automated testing using Selenium IDE

📊 Predictive analytics using machine learning on the Breast Cancer dataset

🤖 Ethical reflection and innovation proposal in AI-driven software engineering

Each section demonstrates how AI enhances productivity, testing efficiency, and decision-making in real-world software engineering contexts.
